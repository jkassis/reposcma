# RepoSCMA

By Jeremy Kassis and the RepoSCMA Working Group.

This repository hosts a GitHub Pages style manifesto for RepoSCMA: an opinionated repo documentation model for managing SCMA artifacts, structure graphs, and task state alongside code.

RepoSCMA is motivated by a practical problem in AI-assisted development: developers and agents need predictable repo-local structure so they can move across repositories, find the same kinds of context, and produce consistent results without rebuilding the map from scratch each time.

Site pages:

- `index.md`: manifesto and TL;DR
- `glossary.md`: SCMA and RepoSCMA terms
- `examples/orderhub.md`: fictional system example
